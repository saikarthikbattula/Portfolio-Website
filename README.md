# Sai Karthik Battula — Portfolio

A responsive React + Vite portfolio. The Headstarter section showcases Pantry, Support Studio, Recall, and Faculty Lens; links point to the verified existing GitHub repositories. Faculty Lens remains local until a repository is created.

Node 22+: `npm ci`, `npm run dev`, and `npm run build`. Deploy the `dist` folder to Vercel or any static host. Open Graph metadata and Person structured data support search previews; no ranking claim is made. Set the optional `VITE_GA_ID` at build time to enable visitor-controlled analytics. Analytics stays off until the visitor opts in. The build does not require external credentials.

Use `docs/portfolio-demo-script.md` in the parent Headstarter workspace for a two-minute walkthrough. Domain purchase, DNS configuration, a published walkthrough video, and top-ten search ranking remain external tasks.
